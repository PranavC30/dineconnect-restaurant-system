⚙️ How to Configure

You can easily switch between modes by changing one parameter:

🎯 For Single Spin Mode (Recommended for Production):

<SpinWheel onClose={() => setShowSpinWheel(false)} onWin={handleSpinWin} allowMultipleSpins={false} // Single spin only resetKey={tableSlug} />

🔄 For Multiple Spins Mode (Great for Demos):

<SpinWheel onClose={() => setShowSpinWheel(false)} onWin={handleSpinWin} allowMultipleSpins={true} // Unlimited spins resetKey={tableSlug} />

💡 Recommendations:

  • 🏪 Restaurant Production: Use allowMultipleSpins={false}
  • 🎪 Special Events: Use allowMultipleSpins={true}
  • 🧪 Testing & Demos: Use allowMultipleSpins={true}
  • 📱 App Store Demos: Use allowMultipleSpins={true}

🎯 When to Use Each Mode

🎯 Single Spin Mode

  • 🎯 Marketing: "Once per visit" creates urgency

🔄 Multiple Spins Mode

  • 🎪 Events: Grand openings, festivals
  • 🧪 Testing: Feature development
